# Ontology glossary — cited external terms (S5)

Borrowed vocabulary used by the ontology_convention_stack conventions.
Each entry carries its URI, license, and how this repo uses the term —
per-citation compliance (MIT/CC-BY-SA), never wholesale copying. The
companion convention: borrowed NAMES in code carry the citation in the
module docstring (`seed_concepts.py` → SKOS, `backfill_row_provenance.py`
→ PROV-O); borrowed DEFINITIONS live here with the per-entry
attribution block. `derive_hyperedges.py`'s event role labels
(acquirer/target/partner) and `cin.py`'s MCA code enums are house or
registrar vocabulary — no external borrow, no citation owed. GDM/OXL
are never cited (verified non-standards).

## ORG `subOrganizationOf`

- **URI:** <https://www.w3.org/TR/vocab-org/#org:subOrganizationOf>
- **Source:** W3C Organization Ontology (ORG), W3C Recommendation
  16 June 2014.
- **License/status:** W3C Software and Document License; use is
  normative-citation only — no text reproduced here.
- **Usage here:** names the semantic of `belongs_to` edges in the
  sector taxonomy (`sub_sector` → `sector` → `super_sector`) and the
  `broader_id` chains those project into the `concepts` table (S2).
  We do NOT materialise ORG triples; the term anchors what the edge
  MEANS when the taxonomy is read against external vocabularies.

## schema.org `Corporation`

- **URI:** <https://schema.org/Corporation>
- **Source:** schema.org vocabulary (schema.org community release).
- **License/status:** CC-BY-SA 4.0 (attribute "schema.org"; definitions
  are community-developed). Cited for term alignment only.
- **Usage here:** the external referent for `entities.entity_type =
  'company'` when company rows are crosswalked (S2 `concept_mappings`)
  or resolved externally (S3 identifiers). The vault's own company
  semantics stay Indian-market-concrete (CIN, NSE/BSE ticker); the
  citation exists so a future linked-data export maps `company` to a
  term outsiders already know.

## FIBO BE `PrivateLimitedCompany`

- **URI:** <https://spec.edmcouncil.org/fibo/ontology/BE/LegalEntities/LegalPersons/PrivateLimitedCompany/>
- **Source:** EDMC Financial Industry Business Ontology (FIBO),
  Business Entities (BE) module.
- **License/status:** MIT License © EDM Council. Cited as the
  definitional anchor for the Indian `PVT`/`PTC` ownership classes the
  CIN parser (`helpers/core/cin.py`) extracts; FIBO's definition is not
  reproduced — the CIN ownership enum is MCA's, not FIBO's.
- **Usage here:** the S3 `cin_ownership` facet values (`PLC`, `PTC`,
  `OPC`, `FTC`, `GOI`, `SGC`, `NPC`) are MCA registrar codes; FIBO BE
  supplies the cross-vocabulary READING of "private limited" when
  ownership classes are mapped to external financial ontologies. It is
  a glossary anchor, not a runtime dependency.

## SKOS `exactMatch`

- **URI:** <https://www.w3.org/TR/skos-reference/#exactMatch>
- **Source:** W3C SKOS Reference, W3C Recommendation 18 August 2009.
- **License/status:** W3C Software and Document License; the precise
  semantics (disjoint concepts, no subsumption inference) are
  normative-citation only.
- **Usage here:** the ONE crosswalk predicate materialised in
  `concept_mappings.match_type` (S2, D-O1: crosswalks live only there).
  Current rows are the operator-curated Yahoo-industry → `sub_sector`
  map (`SUB_SECTOR_ALIASES`) — links between the industry label scheme
  and the taxonomy that assert precise-enclusive identity for
  retrieval. `closeMatch`/`broadMatch`/`narrowMatch` are CHECK-enforced
  values reserved for looser future mappings (e.g. NIC-2008 → ISIC).

## PROV-O `wasGeneratedBy`

- **URI:** <https://www.w3.org/TR/prov-o/#wasGeneratedBy>
- **Source:** W3C PROV-O: The PROV Ontology, W3C Recommendation
  30 April 2013.
- **License/status:** W3C Software and Document License; normative
  semantics cited, not reproduced.
- **Usage here:** names the lineage the S1 row-provenance columns
  capture — every fact-table row is an entity "generated by" an agent
  (`agent_id` → `provenance_agents`, a PROV Agent registry) at a
  trust tier (`source_tier`). We store the Starting-Point binary
  relation as columns on the rows themselves (SQLite conventions, not
  triples); `wasGeneratedBy` is the external reading of
  "row ← agent".

## Citation policy (fixed by S5)

1. Borrowed NAMES in code → cite in the module docstring (URI + spec
   name); no license block needed in code — this file carries it.
2. Borrowed DEFINITIONS in docs → per-entry block (URI + source +
   license/status + usage) as above; never inline-copy definitional
   text from MIT/CC-BY-SA sources without the block.
3. GICS is proprietary: opaque code strings only, with attribution,
   never tree structure. GDM/OXL: never (non-standards).
